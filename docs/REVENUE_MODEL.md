# Modele economique

## Sources de revenus

### 1. Abonnement All Access (B2C/B2B)
- Prix : 99$/mois par seat
- Marge : ~85% (LLM marginal < 15$/user/mois)

### 2. Pay-per-call
- 0.02$ a 0.10$ par call
- Cible : freelances, side-projects

### 3. Revenue share createurs (v1.0)
- 70% createur / 30% plateforme
- Stripe Connect, mensuel

### 4. Enterprise
- 2 000-50 000$/mois selon volume
- Agents custom, SLA 99.9%, SSO, on-premise

### 5. Token $FORGE (Q4 2026)
- Staking, gouvernance, reduction fees (jusqu'a 50% off)

## Projections

- Annee 1 : 1 000 users = **1.5M$ ARR**
- Annee 2 : 10 000 users = **15-27M$ ARR**
- Annee 3 : token + international = **50-100M$ ARR**

## CAC / LTV

- CAC cible : < 30$
- LTV moyen : 600$
